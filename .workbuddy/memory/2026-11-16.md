# 2026-11-16

## GeoChat 复刻项目

- 参考站 `https://geogebra-webchat.348349.xyz/` 为 Solid.js 单页应用，核心能力是自然语言转 GeoGebra 命令、多模型服务商、图片读题、画板导出与历史。
- 在当前空目录从零实现 React 19 + TypeScript + Vite 6 + Express 4 应用，单端口 5173，开发时由 Vite middleware，生产时由 Express 托管 `dist/`。
- 三种解析模式：本地规则、服务端 AI（环境变量 `AI_API_KEY`）、自有 OpenAI 兼容接口（Key 仅内存）。
- GeoGebra 官方脚本回调必须使用 `appletOnLoad`，参考站封装层的 `appletOnReady` 不适用于官方 deployggb.js。
- 作图中 `TriangleCenter(A,B,C,n)` 在当前 GeoGebra Classic 中执行失败。已改为中垂线交点求外心、`Center(Incircle(...))` 求内心、中线交点求重心、高线交点求垂心。
- 命令执行前保存 GGB Base64 快照，失败自动回滚，避免画板留下半成品。
- 本地解析覆盖函数/抛物线、三角形中线高线四心、圆、正多边形、向量、椭圆和常见直线；命令必须通过前后端白名单。
- 窄屏 ≤620px 的画板自动执行 `SetPerspective("G")`，避免代数区占满整个画板。

## API Key 调查

- 参考站公开 bundle 中未发现 `sk-`、Google API Key 或硬编码 Bearer。
- 前端通过 `GET /llm-proxy` 获取 baseURL、model、`serverKey` 布尔值；实际返回 `serverKey:true`、`baseURL:https://api.deepseek.com/v1`、`model:deepseek-flash`。
- 真实 Key 由 EdgeOne Makers 的 `MAKERS_MODELS_KEY` 服务端注入，未下发浏览器，未尝试绕过权限。
